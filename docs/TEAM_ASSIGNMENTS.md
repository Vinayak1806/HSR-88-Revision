## Default Ticket Assignment

Tickets in [LINEAR_TICKETS.md](LINEAR_TICKETS.md) carry an **Assignee** column referencing the Intern ID above. The PM re-balances weekly based on capacity.

## Escalation

- **Blocked on another intern's work** → ping them in Slack; if not resolved in 4 hours, ping the lead.
- **Blocked on a decision** → ask in `#neet-community` with the specific question and options.
- **Blocked on infra / access** → PM owns.
