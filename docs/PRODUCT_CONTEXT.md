# Product Context

Condensed reference derived from the NEET Aspirants Community PRD v1.0 (August 2026). Read this before designing or reviewing any feature.

## Vision

Build a highly accessible AI-powered NEET preparation community where students can access high-quality practice, testing, performance analysis, and basic AI doubt solving **without paying for core preparation resources**.

## Users

- **Primary:** NEET aspirants (may include minors — treat privacy/safety as first-class)
- **Secondary:** Parents (future stakeholder)
- **Internal:** Content editors, academic reviewers, community moderators, platform administrators

## Core Modules

| Module               | Purpose                                                                 |
|----------------------|-------------------------------------------------------------------------|
| Student Dashboard    | Today's quiz, remaining AI doubts, streak, upcoming tests, prep score, weak topics, personalized recommendations |
| Quiz & Test System   | Daily / weekly / monthly quizzes; chapter, subject, full-syllabus mocks; major test series |
| AI Doubt Solver      | 5 free daily sessions; NEET-focused tutor tone; explanations + exam relevance |
| Performance Analytics| Score, accuracy, rank, percentile, subject/chapter breakdown, time analysis, mistakes, trends |
| Community            | Subject discussions, question discussions, study strategy, motivation, future study groups |
| Notifications        | Daily quiz reminders, test reminders, results, streak reminders, personalized recommendations |
| Admin tooling        | Question / test management, AI question generation, AI validation, AI test generation |

## Quiz / Test Structure

- **Daily quiz** — 10–20 questions, mixed subjects & difficulty, timed, instant analysis
- **Weekly quiz** — larger; score, rank, percentile, subject and chapter analysis
- **Monthly test** — substantial NEET-style; negative marking; detailed analysis and ranking
- **Major test series** — chapter-wise, subject-wise, full-syllabus NEET-style tests

## Gamification

Daily and long-term streaks, badges, test-specific rankings, daily/weekly/monthly leaderboards, subject achievements.

## Trust & Safety

- Academic correctness is critical. AI-generated content **must pass validation** before becoming trusted content.
- High-risk AI questions route to academic reviewers.
- Community content is moderated by a combination of automated checks and human review.
- Audience may include minors — privacy, safety, parental/guardian considerations and applicable child/teen requirements must be reviewed before launch.

## Monetization

- Core preparation experience stays **free**.
- Future revenue: premium AI, premium test series, expert doubt solving, partnerships, controlled advertising.
- Mobile ads: **Google AdMob**. Website ads: **Google AdSense** where eligible.

## Scope by Phase

**MVP**

- Registration/login
- Student dashboard
- Daily/weekly/monthly quizzes
- Major test engine
- Results and basic analytics
- 5 daily AI doubt sessions
- Notifications
- Admin question/test management
- AI question generation
- AI validation
- AI test generation

**Phase 2** — community, leaderboards, advanced analytics, personalized tests, AI performance coach, streaks, badges, multilingual AI.

**Phase 3** — parent dashboard, human expert doubts, study groups, voice/image doubts, advanced personalization, stronger exam integrity controls.

## Success Metrics

- **Acquisition** — registrations, new users
- **Engagement** — DAU, MAU, quiz completion, test participation, sessions
- **Learning** — accuracy and score improvement
- **AI** — usage, resolution feedback, quality
- **Retention** — D1, D7, D30
- **Community** — posts, replies, active users

## Success Definition

Success = students return consistently, practice, resolve doubts, understand mistakes, and demonstrate measurable improvement. Not merely registration growth.
