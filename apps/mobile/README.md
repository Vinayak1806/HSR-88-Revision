# NEET Community — Mobile

Flutter 3.19+ app for Android and iOS.

## Setup

```bash
flutter --version           # confirm 3.19+
cd apps/mobile
cp .env.example .env
flutter pub get
flutter run                 # pick an Android emulator or iOS simulator
```

> **Note:** The `android/` and `ios/` platform folders are generated by Flutter. Run `flutter create .` inside `apps/mobile/` on first checkout to materialize them (they are intentionally not committed at scaffold time). Then `flutter run`.

## Scripts

```bash
flutter pub get
flutter analyze
flutter test
flutter run
flutter build apk --release        # Android release
flutter build ios --release        # iOS release (needs Xcode)
```

## Structure

```
lib/
├── main.dart            # entry — loads .env, ProviderScope
├── app.dart             # MaterialApp.router + GoRouter config
├── theme/               # ThemeData light/dark
├── screens/             # top-level route widgets
├── widgets/             # shared widgets
├── services/            # API client, secure storage, providers
├── models/              # data classes
└── ...
test/                    # flutter_test suites
```

## Conventions

- **State:** Riverpod. UI state via providers; server state via providers wrapping the API client.
- **Nav:** GoRouter — declarative, deep-link friendly.
- **HTTP:** Dio via `services/api_client.dart` (interceptor attaches the JWT).
- **Local storage:** `flutter_secure_storage` for tokens; `shared_preferences` for small non-sensitive prefs.
- **Env:** `flutter_dotenv` — variables loaded at startup.
- **Widgets:** prefer `const` constructors; small widgets; no business logic in `build`.

## Env

See [../../docs/ENVIRONMENT.md](../../docs/ENVIRONMENT.md). On Android emulator, `API_BASE_URL=http://10.0.2.2:4000/api` to reach the host's localhost.

## Release

- **Android:** signed AAB via `flutter build appbundle`; upload to Play Console.
- **iOS:** archive via Xcode; upload to App Store Connect.
- Increment `pubspec.yaml` `version:` on every release.
